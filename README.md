# dps-3005-case

Most of the ESPHome configuration is copied from https://github.com/syssi/esphome-dps. Thanks for figuring out how to communicate with the DPS!

The 3d object files were created using Fusion360. You can find both ready-to-slice STL and STEP files.

You can find a blog post about the whole project here: https://blog.commanderred.xyz/2025/05/02/making-a-3d-printed-case-for-a-dps3005/
